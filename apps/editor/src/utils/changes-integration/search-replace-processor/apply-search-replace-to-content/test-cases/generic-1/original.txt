## Quick start

Get started building with CWC in VS Code, Cursor, Antigravity, etc. by running the installation script.

**macOS/Linux/WSL**

```
sh <(curl -fsSL [https://github.com/CodeWebChat/CWC/raw/refs/heads/main/install.sh](https://github.com/CodeWebChat/CWC/raw/refs/heads/main/install.sh))
```

<a href="https://github.com/CodeWebChat/CWC/blob/main/install.sh">View install script</a>

**Windows**

```
irm [https://github.com/CodeWebChat/CWC/raw/refs/heads/main/install.ps1](https://github.com/CodeWebChat/CWC/raw/refs/heads/main/install.ps1) | iex
```

<a href="https://github.com/CodeWebChat/CWC/blob/main/install.ps1">View install script</a>

> [!IMPORTANT]
> To mitigate commonly exploited supply chain vulnerabilities, the extension is not available in the Marketplace. Instead, the installation script compiles it on your machine, directly from this public repository.
